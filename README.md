# SEDODLearn — Plateforme d'apprentissage du développement web

SEDO est une plateforme web éducative conçue pour accompagner les débutants dans l'apprentissage du développement web.

La plateforme propose un parcours progressif permettant de découvrir les fondamentaux du Web, puis d'apprendre HTML et CSS à travers des modules structurés, des leçons et des exercices interactifs.

## Démo

Accéder à la plateforme :

https://sedod.github.io/sedo/

## Objectifs du projet

SEDO a été conçu pour :

- faciliter l'apprentissage du développement web ;
- proposer un parcours pédagogique progressif ;
- permettre aux apprenants d'avancer étape par étape ;
- présenter les notions fondamentales du Web ;
- apprendre les bases de HTML et CSS ;
- permettre aux apprenants de suivre leur progression.

## Fonctionnalités

### Parcours d'apprentissage

La plateforme propose plusieurs modules :

- Introduction au Web
- HTML
- CSS

### Modules progressifs

Les modules sont organisés de manière progressive afin de permettre à l'apprenant de construire ses connaissances étape par étape.

### Leçons

Chaque module contient plusieurs leçons présentant les notions essentielles avec des explications, des exemples et des exercices.

### Quiz et exercices

Des exercices sont intégrés au parcours afin de permettre aux apprenants de vérifier leur compréhension.

### Suivi de progression

Une barre de progression permet de visualiser l'avancement de l'apprenant dans son parcours.

### Navigation interactive

La plateforme dispose d'une navigation permettant de passer facilement d'un module ou d'une leçon à l'autre.

### Mode sombre

Un mode sombre est disponible pour améliorer le confort de lecture.

## Technologies utilisées

Le projet a été développé avec :

- HTML5
- CSS3
- JavaScript

Des ressources externes sont également utilisées pour certaines fonctionnalités, notamment PrismJS pour la coloration syntaxique du code.
